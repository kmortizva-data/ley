# Ley

Registro de entrenamiento para el celular: propone el peso y las repeticiones de cada sesión,
cronometra los descansos, grafica el progreso y calcula metas de calorías y proteína.
Cada regla enlaza al estudio que la respalda (Ajustes, "La ciencia detrás").

Los datos se guardan solo en tu dispositivo. Funciona sin conexión.

Pautas generales basadas en estudios publicados, no un plan médico.
